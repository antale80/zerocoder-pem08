# Анализатор рынка визуальных конструкторов сайтов

PEm08 · Александров Антон · 23.10.2026. Адаптация исходника Toxap/pem08, commit указан в PROVENANCE.md.

## Кейс

Ниша — создание лендингов и сайтов без программирования. Конкуренты: Tilda, Framer, Readymag. В data/ сохранены три реальных снимка официальных сайтов, краткие пересказы и снимки доступного текста интерфейса. Дата и происхождение — в data/manifest.json. Это материалы для анализа, а не готовые выводы о продуктах. Три вымышленных примера *Demo оставлены для тестов, в основной набор не входят.

## Запуск на Mac и Windows

1. Откройте терминал в этой папке. Установите Python 3.13 и Chrome, если их нет.
2. `python -m venv .venv`
3. Активируйте: Mac `source .venv/bin/activate`; Windows PowerShell `.venv\Scripts\Activate.ps1`.
4. `python -m pip install -r requirements-lock.txt` — версии локальной проверки. Для desktop дополнительно `python -m pip install -r requirements-desktop.txt`.
5. Скопируйте `.env.example` в `.env`. Локально заполните OPENAI_API_KEY или PROXY_API_KEY. Ключ не присылайте в чат и не загружайте в GitHub.
6. `python run.py`; откройте http://127.0.0.1:8000. Либо `python -m uvicorn run:app --host 127.0.0.1 --port 8000`.

Без ключа сайт запускается, но явно сообщает, что анализ API не выполнен. Доступность модели и квота конкретного аккаунта не проверены. Модели можно изменить в .env. Настроенный OpenAI-совместимый ответ JSON проходит проверку Pydantic. Для текста design_score=null; для изображения — 0..10 с обоснованием. animation_potential всегда предложение, не наблюдение реальной анимации.

## Проверки и результаты

`python -m unittest test_app -v` — 9 локальных тестов, включая заглушки модели и браузера. Они не подтверждают реальный LLM-анализ или Selenium. Подробный протокол: ../evidence/local-tests.txt.

После подключения ключа: `python verify_live.py` — шесть платных вызовов API на трёх публичных учебных материалах; ответы в runtime/live. Размер и стоимость зависят от выбранной модели и аккаунта.

`python verify_selenium.py` — отдельный реальный сбор трёх сайтов Chrome/Selenium; сохраняет JSON и PNG в runtime/selenium без API. Во время подготовки не запускался. Затем через веб-интерфейс запустите сбор и анализ выбранного конкурента: /parsedemo, история /history. Блокировки сайтов и динамические изменения могут потребовать доработки; защиты сайтов не обходите.

Основные маршруты: /analyzetext, /analyzeimage, /parsedemo. Исходные /analyze_text, /analyze_image, /parse_demo сохранены. Файлы сервисов в исходнике называются openai_service.py и parser_service.py, в задании имена написаны иначе.

## Windows desktop

На Windows: `python -m pip install -r requirements-desktop.txt`, затем `python build.py`. Результат: dist/competitionmonitor.exe. Перенесите локальный .env рядом с exe (не включайте его в распространяемый архив). Chrome требуется отдельно. Launcher поднимает backend на 127.0.0.1:8000; порт должен быть свободен. История Windows — %LOCALAPPDATA%/PEm08/history.json. Исходный интерфейс PyQt6 сохранён; расширенные поля доступны через API и веб-интерфейс.

Сборка и запуск exe в Windows не выполнялись. PyInstaller требует сборку под целевой ОС: https://www.pyinstaller.org/en/stable/operating-mode.html . Сценарий сборки подготовлен, успешная сборка не заявляется.
