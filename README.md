Модель иногда делает неподтверждённые выводы и не согласует сумму компонентов с итоговой оценкой. Баллы 8/8/7 не являются проверенным рейтингом. Строгая JSON-схема проверяет структуру, а не истинность. Сопоставление с источниками и замечания — evidence/final-quality-review.txt. Официальные сайты подтверждают формулировки поставщиков, а не фактическую эффективность функций.

## Запуск исходников

Python 3.13, Chrome для Selenium.

1. `python -m venv .venv`
2. Активировать: Windows `.venv\Scripts\Activate.ps1`; Mac `source .venv/bin/activate`.
3. `python -m pip install -r requirements-lock.txt` для повторения локального окружения; для desktop — дополнительно `python -m pip install -r requirements-desktop.txt`.
4. `python connect_and_serve.py`; открыть http://127.0.0.1:8000/connect и ввести ключ OpenAI или Proxy API. Ключ хранится в памяти до остановки процесса.
5. Открыть http://127.0.0.1:8000/ . Доступны текст, изображение, Selenium и история.

Альтернатива: скопировать .env.example в .env, заполнить один ключ и выполнить `python run.py`. .env не включать в репозиторий или архив.

## Windows exe

Файл находится в ../windows/competitionmonitor.exe. Для использования модели создайте локальный .env рядом с exe по примеру .env.example. Нужен свой API-ключ; в сборке ключей нет. Chrome требуется для сбора сайтов. Перед запуском освободите порт 8000. История сохраняется в %LOCALAPPDATA%/PEm08/history.json.

Для самостоятельной сборки на Windows: `python -m pip install -r requirements-desktop.txt`, затем `python build.py`. Результат dist/competitionmonitor.exe. `competitionmonitor.exe --smoke-test` проверяет запуск без запроса к модели.

## Файлы и проверка

data/manifest.json — реальные конкуренты, URL и происхождение файлов. Три *Demo являются вымышленными тестовыми страницами.
`python -m unittest test_app -v` — локальные тесты.
verify_live_v2.py — 6 реальных запросов без автоматических повторов; переменная PEM08_BASE задаёт локальный адрес. По умолчанию порт 8001 использовался в финальной практике; для обычного запуска задайте http://127.0.0.1:8000 . Запуск использует квоту API.
verify_selenium.py — отдельный сбор трёх сайтов без LLM; в финальной практике через интерфейс проверялся Tilda.

Основные маршруты: /analyzetext, /analyzeimage, /parsedemo, /history. Исходные варианты с подчёркиваниями сохранены. Ключи, .env, runtime и журналы не публикуются. Источник кода и изменения — PROVENANCE.md.
